# PifinApps tanıtım sitesi

- `index.html`: PifinApps ana sayfa
- `sahaf/index.html`: Sahaf tanıtım sayfası
- `neyyapimi/index.html`: Neyyapimi / Pifin Ney Açkı Sistemi tanıtım sayfası
- `assets/`: Orijinal marka görselleri ve Sahaf uygulama ekran görüntüleri

## GitHub Pages'e yükleme
ZIP içeriğini (klasörün kendisini değil) `pifinapps.github.io` deposunun ana dizinine yükleyin. `index.html` ana dizinde olmalı. Settings → Pages altında `main` ve `/(root)` seçili olmalı.

Yayın adresleri:
- https://pifinapps.github.io/
- https://pifinapps.github.io/sahaf/
- https://pifinapps.github.io/neyyapimi/

Logolar, sağlanan orijinal dosyalardan kullanılır. Tasarım, sembol ve renkleri değiştirilmemiştir.
